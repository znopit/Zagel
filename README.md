# Zagel — everything about Zoi

A private, offline PWA: days, small parties, wishes, fashion studies, loose thoughts, picture books and a book of spells, laid out along a witches' road. By night the museum closes and the creatures wake up.

- Everything is stored in the browser's IndexedDB on your own device. Nothing is sent anywhere.
- Backup / restore / send to iPad live in **Home** (the dollhouse at the end of the road).
- Plain HTML, CSS and JavaScript. No build step.

## Install
Open the GitHub Pages link in Safari → Share → **Add to Home Screen**.

## Swapping in your own drawings
All creature artwork is SVG in `js/art.js`. Each piece can be replaced with your own drawing later.
